# Viu Growth Audit

**Live → https://eddieatadapty.github.io/viu-flow-rebuild/**

Five ideas to turn more Viu users into subscribers, each built into a clickable version of Viu's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask at the first ad break, not before the first episode | +10–20% CR to purchase |
| 02 | Use the genres they pick | +8–15% CR to purchase |
| 03 | Test three offers on one paywall, without a release | +10–15% ARPU |
| 04 | Catch the ✕ with a one-week pass | +10–15% ARPU |
| 05 | Show what Premium changes, next to your rating | +5–15% CR to purchase |

Every price, rating and feature comes from Viu's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Viu. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
